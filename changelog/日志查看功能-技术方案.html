系统日志查看功能 - 技术方案 ​

1. 概述 ​

在 EMS Simulate 系统右上角添加日志按钮，点击后以弹框形式展示系统日志，支持按模块、按设备筛选，日志仅显示日期和内容。

2. 功能需求 ​

  • 入口：右上角导航栏新增日志图标按钮
  • 展示形式：Element Plus Dialog 弹框，覆盖在主界面之上
  • 日志筛选：
    • 按模块筛选：系统、Web服务、IEC61850、IEC104、模拟器
    • 按设备筛选：选择"系统"模块时，可进一步筛选具体设备
  • 日志显示：仅显示日期时间 + 日志内容，按时间倒序排列
  • 自动刷新：支持开关自动刷新（默认关闭），轮询间隔 5 秒
  • 日志来源：读取后端日志文件

3. 后端方案 ​

3.1 新增 API 端点 ​

在 FastAPI 中新增 /api/logs 路由：

方法路径说明
GET/api/logs/modules获取可用日志模块列表
GET/api/logs/devices获取有独立日志的设备列表
GET/api/logs/query查询日志内容（支持分页、筛选）

3.2 日志文件映射 ​

模块名称日志文件路径说明
system{LOG_DIR}/ems_simulate.log系统主日志
web{LOG_DIR}/web.logWeb 服务日志
iec61850{LOG_DIR}/iec61850.logIEC 61850 协议日志
iec104{LOG_DIR}/iec104.logIEC 104 协议日志
simulator{LOG_DIR}/simulate.log模拟器日志
device{LOG_DIR}/{device_name}/{device_name}.log各设备独立日志

3.3 日志读取逻辑 ​

  • 使用 loguru 的日志格式为：[时间] [模块:函数:行号] [级别] 消息
  • 后端读取日志文件，按行解析，提取时间戳和消息内容
  • 支持 offset（偏移行数）和 limit（返回条数）实现分页
  • 支持 module 和 device 筛选参数
  • 支持 keyword 关键词搜索
  • 按时间倒序返回（最新的在前）

4.4 交互流程 ​

  1. 用户点击右上角日志图标按钮
  2. 弹框打开，自动加载最新日志（默认选择"全部模块"）
  3. 用户选择模块筛选器 → 触发重新查询
  4. 若选择"系统"模块 → 启用设备筛选器
  5. 用户开启自动刷新 → 每 5 秒轮询一次最新日志
  6. 点击关闭按钮或按 ESC 关闭弹框

5. 数据结构 ​

typescript
// LogEntry
interface LogEntry {
  time: string    // "2026-07-06 14:32:15"
  content: string // "设备 [RTU-01] 连接成功"
}

// LogQueryParams
interface LogQueryParams {
  module?: string
  device?: string
  offset: number
  limit: number
  keyword?: string
}

// LogQueryResponse
interface LogQueryResponse {
  total: number
  offset: number
  limit: number
  logs: LogEntry[]
}
