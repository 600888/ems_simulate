# IEC 60870-5-104 报文查看

## 进入报文查看

1. 在左侧设备树中选中 IEC104 设备；
2. 点击右侧上方的"**报文**"图标；
3. 窗口中实时展示 APDU 帧，支持暂停、筛选、报文详情与原始字节定位。

![](images/iec104-message.png)

## APDU 基本结构

每条 APDU 由 **启动字符 + 长度 + 控制域 +（可选）ASDU** 组成：

```
┌──────────┬──────────┬──────────────┬───────────────┐
│ 启动字符 68H │ 长度 L    │ 控制域 4 字节  │ ASDU（I 帧）   │
└──────────┴──────────┴──────────────┴───────────────┘
```

- 启动字符：固定 `0x68`；
- 长度：控制域 + ASDU 的字节数（U/S 帧无 ASDU，长度为 4）；
- 控制域：标识帧类型与序号。

## 三类帧

| 帧类型 | 控制域特征 | 用途 |
|--------|-----------|------|
| **U 帧** | 第 1 字节为 `0x07`（STARTDT）/ `0x0B`（STOPDT）/ `0x43`（TESTFR） | 链路控制：启动/停止/测试 |
| **S 帧** | 第 1 字节低 4 位为 1（如 `0x01`） | 对 I 帧的接收确认 |
| **I 帧** | 第 1 字节低 1 位为 0 | 携带 ASDU 数据 |

## ASDU 结构

I 帧的数据部分为 ASDU（应用服务数据单元）：

```
┌──────────────┬────────────┬──────────┬──────────────┬──────────────────┐
│ 类型标识      │ 可变结构限定词 │ 传送原因   │ 公共地址 COA   │ 信息对象（1..N 个） │
│ 1 字节       │ 1 字节      │ 2 字节    │ 2 字节        │                  │
└──────────────┴────────────┴──────────┴──────────────┴──────────────────┘
```

| 字段 | 说明 |
|------|------|
| 类型标识 | 如 `0x0D`（13 = M_ME_NC_1 短浮点遥测） |
| 可变结构限定词 | 信息对象数量 + 寻址方式（连续/单一） |
| 传送原因 | 周期（1）、背景（2）、自发（3）、总召唤（20）、命令确认等 |
| 公共地址 | 站地址（COA） |
| 信息对象 | 信息体地址（IOA）+ 值 + 品质描述符 + 时标 |

## 请求 / 响应示例

**总召唤请求（C_IC_NA_1）**：

```
68 0E 00 00 00 00 64 01 06 00 01 00 00 00 00 14
│  │  │  │  │  │  │  │  │  │  │  │  └───────── 召唤限定词 0x14（全部数据）
│  │  │  │  │  │  │  │  │  │  │  └──────────── 信息体地址 0
│  │  │  │  │  │  │  │  │  │  └─────────────── 公共地址 0x0001
│  │  │  │  │  │  │  │  │  └────────────────── 传送原因 6（激活）
│  │  │  │  │  │  │  │  └───────────────────── 可变结构限定词 01（1 个对象）
│  │  │  │  │  │  │  └──────────────────────── 类型标识 0x64（100 = 总召唤）
│  │  │  │  │  │  └─────────────────────────── 控制域：发送序号 0
│  │  │  │  │  └────────────────────────────── 控制域 3 字节
│  │  │  │  └───────────────────────────────── 长度 = 14
│  │  │  └──────────────────────────────────── 启动字符 68H
```

**总召唤确认**：传送原因 7（激活确认），随后服务端以传送原因 20（响应总召唤）上送各测点 I 帧。

## 报文解析功能

平台自动解析并展示：

- **帧类型**：U / S / I 帧；
- **类型标识**：ASDU 名称（如 `M_ME_NC_1`）；
- **传送原因**：周期、自发、总召唤等；
- **信息对象**：信息体地址、测量值（按系数换算）、品质描述符（IV/NT/SB/BL/OV 含义）；
- **序号**：I 帧的发送/接收序号（用于滑动窗口分析）。

## 排查技巧

- **链路无法建立**：检查是否有 U 帧 STARTDT 激活与确认；
- **数据不刷新**：查看 I 帧是否周期性上送、S 帧确认是否正常；
- **窗口拥塞**：发送序号与确认序号差距接近 k 值说明接收方未及时确认；
- **品质无效**：查看 QDS 的 IV 位是否置位。
