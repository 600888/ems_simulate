# IEC 61850 协议介绍

## 协议概述

IEC 61850 是**新一代智能变电站通信标准**，定义了变电站自动化系统的信息建模、通信服务与工程配置，是智能变电站的核心标准。与传统的"点表式"协议不同，它采用**面向对象的数据模型**（IED → 逻辑设备 → 逻辑节点 → 数据对象 → 数据属性），自描述能力强。

EMS Simulate 基于 `pyiec61850-ng` 库实现，提供 **MMS / GOOSE / Reports / Files / SCL / 建模工作台** 完整功能链，可模拟完整的智能变电站 IED 设备，也可作为客户端连接真实 IED。

## 子模块一览

| 子模块 | 服务端 | 客户端 | 说明 |
|--------|:------:|:------:|------|
| **MMS / 数据模型** | ✅ | ✅ | 制造报文规范：数据读写、模型浏览与导出（ICD/XML/JSON/CSV） |
| **GOOSE** | ✅ | ✅ | 通用面向对象变电站事件：发布/订阅/抓包，支持真实网卡选择 |
| **Reports** | ✅ | ✅ | BRCB / URCB 报告控制块，数据变化/品质变化/总召唤触发 |
| **Files** | ✅ | ✅ | 文件目录浏览与传输 |
| **SCL** | ✅ | — | ICD/CID/SCD 文件上传、校验、对比与测点/GOOSE/Report 导入 |
| **建模工作台** | — | — | 基于 SCL 文件的模型工程化管理（创建/编辑/校验/发布） |
| **SV** | 规划中 | — | 采样值发布（骨架实现） |

## 数据模型层级

IEC 61850 采用分层对象模型：

```
IED（智能电子设备）
└── AccessPoint（访问点）
    └── Server
        └── LDevice（逻辑设备 LD，如 LD0、PROT）
            └── LN（逻辑节点，如 LLN0、MMXU、XCBR、CSWI）
                ├── DO（数据对象，如 Mod、Pos、TotW）
                │   └── DA（数据属性，如 stVal、q、t、ctlModel）
                └── DataSet（数据集，供 GOOSE / Report 引用）
```

每个数据属性带**功能约束（FC）**，标识数据的用途：

| FC | 含义 | 典型数据 |
|----|------|----------|
| MX | 测量值 | 电流、电压、功率 |
| ST | 状态信息 | 开关位置、状态 |
| CO | 控制 | 分/合闸命令 |
| CF | 配置 | 定值、参数 |
| DC / EX | 描述 / 扩展描述 | 铭牌、说明 |

## 常用逻辑节点

| LN | 名称 | 功能 |
|----|------|------|
| LLN0 | 零类逻辑节点 | 公共数据（Mod、Beh、Health），数据集定义 |
| LPHD | 物理设备 | 设备铭牌、健康状态 |
| MMXU | 测量 | 三相电压/电流/功率 |
| XCBR | 断路器 | 开关位置、分合闸控制 |
| XSWI | 隔离开关 | 位置与控制 |
| CSWI | 开关控制 | 控制接口 |

## 通信服务

| 服务 | 传输 | 说明 |
|------|------|------|
| MMS | TCP 102 端口 | 数据读写、模型浏览、报告、文件服务 |
| GOOSE | 以太网二层组播 | 快速变位广播（<4ms），无需 TCP/IP |
| SV | 以太网二层 | 采样值（规划中） |
| MMS 报告 | TCP | 报告控制块上送（URCB/BRCB） |

## 角色说明

| 角色 | 行为 |
|------|------|
| **服务端（Server）** | 导入 ICD/SCD/CID 模型后模拟 IED：响应 MMS 读写、按报告控制块上送报告、发布/接收 GOOSE、提供文件服务 |
| **客户端（Client）** | 连接真实 IED：动态发现数据模型、读写数据、订阅 GOOSE 与报告、浏览文件 |

## 常用术语

| 术语 | 含义 |
|------|------|
| SCL | 变电站配置描述语言（ICD/CID/SCD 文件） |
| ICD | IED 能力描述文件（单 IED） |
| SCD | 全站系统配置文件 |
| FCDA | 功能约束数据属性（DataSet 成员引用） |
| RCB | 报告控制块（URCB 非缓存 / BRCB 缓存） |
| GCB | GOOSE 控制块 |
