# DL/T 645-2007 协议介绍

## 协议概述

DL/T 645 是中国电力行业**多功能电能表通信协议标准**（1997 年发布，2007 年修订），规定了电能表与数据采集设备（主站）之间的数据交换格式，广泛应用于电能计量、用电信息采集系统。

EMS Simulate 基于 `dlt645[async]` 库实现该协议，支持模拟电能表（服务端/从站）与主站抄表（客户端），并内置标准数据项库与系数转换。

## 协议特点

| 属性 | 说明 |
|------|------|
| 默认端口 | 8899（TCP 封装）/ 串口（RS-485） |
| 帧格式 | 68H 起始符 + 地址域 + 控制码 + 数据域 + 校验码 + 16H 结束符 |
| 地址域 | 6 字节 BCD 表地址（A0~A5） |
| 控制码 | 读数据、写数据、广播校时、读通信地址等 |
| 数据标识 | 4 字节 BCD（DI0~DI3），覆盖 D13~D133 等数据项 |
| 校验 | 从起始符到数据域末尾的累加和（CS） |
| 波特率 | 默认 2400（2007 版支持 1200~9600 自适应） |

## 数据标识体系

数据标识采用 4 字节 BCD 编码，按数据项分类：

| 分类（DI0 高 4 位） | 内容 | 示例 |
|------|------|------|
| 电能量 | 正向/反向有功、无功电能 | `00010000` 当前正向有功总电能 |
| 最大需量及发生时间 | 各费率最大需量 | — |
| 变量 | 电压、电流、功率、功率因数 | `02010100` A 相电压 |
| 事件记录 | 事件发生/结束记录 | — |
| 参变量 | 电表参数（费率、时段等） | — |

常用数据标识示例：

| 数据标识 | 含义 |
|----------|------|
| `00010000` | 当前正向有功总电能 |
| `00020000` | 当前反向有功总电能 |
| `02010100` | A 相电压 |
| `02020100` | A 相电流 |
| `02030000` | 瞬时总有功功率 |
| `02040100` | A 相功率因数 |

## 系数转换

电表原始数据为 BCD 编码的整数，需按数据项的**倍率**换算为真实值：

```
真实值 = 原始值 × 乘法系数 + 加法系数
```

例如正向有功总电能倍率通常为 0.01（单位 kWh），EMS Simulate 内置各数据项的默认倍率，也可在测点中自定义乘法/加法系数。

## 点表模式

EMS Simulate 的 DL/T645 设备支持两种测点配置模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **标准点表** | 从内置 dlt645 标准数据项库自动生成完整点表 | 推荐，开箱即用 |
| **导入点表** | 从 Excel 点表导入自定义配置 | 特殊表型或自定义数据项 |

## 角色说明

| 角色 | 行为 |
|------|------|
| **服务端（从站）** | 软件模拟电能表，响应主站的读/写/校时请求 |
| **客户端（主站）** | 软件作为主站抄读真实电表，验证读取值与系数转换 |
