# DL/T 645-2007 报文查看

## 进入报文查看

1. 在左侧设备树中选中 DL/T645 设备；
2. 点击右侧上方的"**报文**"图标；
3. 窗口中实时展示抄表通讯帧，支持暂停、筛选、报文详情与原始字节定位。

![](images/dlt645-message.png)

DL/T645 帧采用 68H 起始、16H 结束的定界格式：

```
┌──────────┬───────────────┬────────┬──────────┬─────────────────┬────────┬────────┐
│ 起始符 68H │ 地址域 A0~A5    │ 控制码 C │ 数据域长度 │ 数据域（标识+数据） │ 校验 CS │ 结束符 16H │
│ 1 字节   │ 6 字节（BCD）   │ 1 字节  │ 1 字节    │ N 字节           │ 1 字节 │ 1 字节   │
└──────────┴───────────────┴────────┴──────────┴─────────────────┴────────┴────────┘
```

| 字段 | 说明 |
|------|------|
| 起始符 | 固定 `0x68` |
| 地址域 | 6 字节表地址（BCD，倒序传输，A0 最低位） |
| 控制码 | 功能标识（见下表） |
| 数据域长度 | 数据域字节数 L（0~254） |
| 数据域 | 数据标识（DI0~DI3）+ 数据内容（BCD/二进制） |
| 校验码 | 从起始符到数据域末尾各字节的累加和取低 8 位 |
| 结束符 | 固定 `0x16` |

## 控制码说明

| 控制码（D7..D0） | 含义 |
|------|------|
| `0x01` | 读数据（主站请求） |
| `0x81` | 读数据应答（从站响应） |
| `0x04` | 写数据（主站请求） |
| `0x84` | 写数据应答（从站响应） |
| `0x08` | 广播校时 |
| `0x0A` | 读通信地址 |
| `0x91` | 读数据错误应答（D7=1 表示异常） |

## 读数据示例

**读当前正向有功总电能请求**（表地址 `AAAAAAAAAAAA`）：

```
68 AA AA AA AA AA AA 68 01 04 33 33 33 33 08 CS 16
│  │  │  │     │  │  │  │  │  │  └──────── 数据标识 00010000（BCD 倒序）
│  │  │  │     │  │  │  │  │  └─────────── 数据域长度 = 4
│  │  │  │     │  │  │  │  └────────────── 控制码 = 01（读数据）
│  │  │  │     │  │  │  └───────────────── 起始符 68H（地址域前）
│  │  │  │     │  │  └──────────────────── 表地址 A0~A5
│  │  │  │     │  └─────────────────────── 帧起始符 68H
│  │  │  │     └────────────────────────── 数据域长度
```

**应答**：控制码 `0x81`，数据域 = 数据标识 + 电能值（BCD 编码，带倍率换算）。

## 报文解析功能

平台自动解析并展示：

- **控制码**：读/写/校时等操作类型及应答/异常标志；
- **表地址**：从站地址（BCD 还原）；
- **数据标识**：如 `00010000` → 当前正向有功总电能；
- **数据内容**：电能读数、电压值、状态字等（按 BCD 解码）；
- **系数转换**：按测点配置的乘法/加法系数换算为真实值；
- **校验**：显示 CS 校验是否通过。

## 排查技巧

- **无应答**：检查表地址、波特率、校验位、总线接线（A/B 是否接反）；
- **应答异常（0x91）**：数据标识不支持或数据域长度不符；
- **读数偏差**：核对数据标识对应的倍率与系数；
- **校验失败**：排查线路干扰导致的数据位错误。
