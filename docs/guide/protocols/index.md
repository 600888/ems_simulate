# 协议支持

EMS Simulate 支持多种工业通信协议，每种协议均可配置为**服务端**（模拟设备）或**客户端**（读取真实设备），并提供专属的操作界面与通信排查能力。OPC UA 使用会话与服务调用日志进行诊断。

## 协议概览

| 协议 | 服务端 | 客户端 | 默认端口 | 典型设备 |
|------|:------:|:------:|----------|----------|
| [Modbus TCP / RTU](./modbus/) | ✅ | ✅ | 502（TCP）/ 串口（RTU） | PLC、RTU、传感器 |
| [IEC 60870-5-104](./iec104/) | ✅ | ✅ | 2404 | 测控装置、变电站远动 |
| [DL/T 645-2007](./dlt645/) | ✅ | ✅ | 8899 | 智能电能表 |
| [IEC 61850](./iec61850/) | ✅ | ✅ | 102（MMS） | 智能变电站 IED |
| [OPC UA](./opcua/) | ✅ | ✅ | 4840 | 能源设备、PLC、工业数据服务 |

> **角色说明**
>
> - **服务端**：软件模拟真实设备，响应上位机的请求（如响应主站轮询、处理总召唤、应答抄表等）；
> - **客户端**：软件作为上位机主动读取真实设备（用于测试真实设备或验证服务端模拟的正确性）。

## 各协议文档入口

### [Modbus TCP / RTU](./modbus/)

工业自动化领域应用最广泛的通信协议，支持 TCP 网络与 RTU 串口两种模式。

- [协议介绍](./modbus/) · [操作指南](./modbus/operation) · [报文查看](./modbus/packet-view)

### [IEC 60870-5-104](./iec104/)

电力系统远动通信标准协议，广泛用于变电站与调度中心之间的数据传输。

- [协议介绍](./iec104/) · [操作指南](./iec104/operation) · [报文查看](./iec104/packet-view)

### [DL/T 645-2007](./dlt645/)

中国电力行业多功能电能表通信协议标准，用于电表数据采集。

- [协议介绍](./dlt645/) · [操作指南](./dlt645/operation) · [报文查看](./dlt645/packet-view)

### [IEC 61850](./iec61850/)

新一代智能变电站通信标准，提供 MMS / GOOSE / Reports / Files / SCL 完整功能链。

- [协议介绍](./iec61850/) · [操作指南](./iec61850/operation) · [报文查看](./iec61850/packet-view)

### [OPC UA](./opcua/)

支持服务端地址空间建模与变量模拟、客户端浏览和读写、原生实时订阅、历史查询与事件，并提供 MQTT/JSON 发布和证书安全配置。

- [协议介绍](./opcua/) · [操作指南](./opcua/operation) · [报文与诊断查看](./opcua/packet-view)

## 通用能力

EMS Simulate 按协议提供以下能力，具体支持范围见各协议操作指南：

- **通信排查**：支持协议报文查看、详情与原始字节定位；OPC UA 提供会话与服务调用日志；
- **测点体系**：统一的 YC（遥测）/ YX（遥信）/ YK（遥控）/ YT（遥调）测点类型；OPC UA 使用专属点表与 NodeId 映射；
- **数据模拟**：支持随机、自增、自减、计划、正弦波、斜坡、脉冲等方式；OPC UA 提供固定值、随机、正弦波和步进规则；
- **测点映射**：跨设备测点联动与公式计算。

相关通用操作见 [设备管理](../device/device-management) 与 [测点模块](../point/point-types)。
