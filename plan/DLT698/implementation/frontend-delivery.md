# DL/T 698.45 前端交付与验收

日期：2026-10-14

## 范围

依据 `.pen/dlt698.pen` 的功能、交互和仓库已导出的页面预览实现前端。样式沿用现有 Vue 3 / Element Plus 主题与公共组件，不要求逐像素复制设计稿。Pencil 当前没有打开目标文件，因此本次没有改动 `.pen`；核对依据为 [设计说明](../../../.pen/dlt698-design-spec.md) 和 `.pen/previews/dlt698/`。

本次交付前端界面、拟定 HTTP 契约与 [后端实施计划](backend-integration-plan.md)。本次没有添加 Python 协议运行时、数据库迁移或真实认证算法，未进行真实电表通信验证。

## 查看方式

在 `front` 目录执行 `npm run dev`，访问 `http://127.0.0.1:8080/#/dlt698-preview`。

预览支持客户端/服务端切换、中文/英文、分类搜索、标准候选点选择、测点新增/编辑/删除、复合 Data 展开、记录草稿和配置草稿。测点与配置草稿按角色保存到浏览器本地；记录草稿保存在当前页面内存，刷新后清空。可导出 JSON，也可通过“恢复示例”清除当前角色草稿。示例时间和值不是实时读数。

预览中真实设备启动、读取、写入、方法调用、报告发送、代理执行、导入、模拟等动作受禁用控制；可打开的操作表单只用于检查参数界面，不产生通信请求。

正式设备通过现有 `/device/:deviceName` 入口进入，按 `Dlt698Client` / `Dlt698Server` 识别工作区，协议角色优先取持久化 `dlt698_config.role`。数字协议 ID 8 仅在前端预留，添加设备的协议下拉仍由后端返回；没有将尚未实现的协议硬塞进当前后端创建流程。

## 复用与专属部分

| 功能 | 实现方式 |
| --- | --- |
| 设备信息、启动停止、客户端连接与报文入口 | 复用 `Device.vue`、`MessageViewDialog`、`ConnectionMonitorDialog`；继续使用既有 API |
| 网络/串口配置 | 复用 `DeviceFormConfig` 和 `AddDeviceDialog`；仅补协议 8 的参数、默认值、校验和回填 |
| 测点详情五个页签 | 提取 `PointDetailTabs`，既有通用 `Table.vue` 和 DLT698 表格共同使用；原协议页签内容和事件保留 |
| 映射、模拟与变化回溯 | 复用 `PointMappingConfig`、`PointSimulator`、`PointChangeHistory`；等待后端声明 typed Data 适配能力再加载 |
| 公共模拟配置 | 沿用现有 `SimulationConfigDialog`；客户端禁用，服务端同时检查后端 simulation capability |
| OAD、精确类型、工程值及数组结构 | 新增 DLT698 专属列和 Data 编辑器，避免套用 Modbus 的寄存器地址与浮点转换 |
| 记录、REPORT、PROXY | 协议工作区提供专用条件、参数与结果区域，不新增通信日志/连接监控业务页签 |

核心入口：[Dlt698Panel.vue](../../../front/src/components/device/dlt698/Dlt698Panel.vue)、[契约](../../../front/src/types/dlt698.ts)、[API](../../../front/src/api/dlt698Api.ts)、[语义工具](../../../front/src/utils/dlt698.ts)。

## 已实现的界面状态

- 客户端测点分类、名称/OAD/编码搜索、选择与分页、普通/批量读取、自动读取间隔与后台任务状态；完整批次另表展示，保留重复请求项与序号。
- 标准候选目录、完整属性与元素说明、显式逐项验证；预览候选只是设计示例，完整目录和设备布局校验由后端提供。
- 添加/编辑测点、OAD 组合、类型/范围校验；标准定义的单位/倍率和权限不能通过普通属性编辑随意更改。
- UInt64/Int64 以十进制字符串处理；工程值通过整数运算计算，数组/结构按精确子类型树展示。
- SET、ACTION、服务端本地发布值修改的独立表单；逐项 DAR/可选 Data、失败与执行结果未知状态，重新读取与重新执行分离。
- 日冻结、月冻结、掉电与初始化记录条件；精确时间、半开时间/序号区间、最近第 n 次；真实响应列、空结果、DAR、分块统计和取消等待。
- 服务端记录新增与精确 Data[] 校验；不提供没有实现依据的自动周期冻结开关。
- 上报接收与服务端发送表单、关联会话选择、PIID-ACD、确认状态；代理路由只绑定真实关联会话。
- TCP/串口方向和协议角色分别配置；SA/CA、公共/预设关联、LINK/心跳、CONNECT 参数与协商值；认证后端缺失时明确说明。
- 状态覆盖停止、监听、关联中、已关联、请求中、超时、拒绝、取消、失效。监听不等于已关联，端口 0 不等于未配置。

## 验证

- `npm run type-check`：通过。
- `node node_modules/vite/bin/vite.js build --outDir ../.tmp/dlt698-build`：通过；产物写到临时目录，没有覆盖用户已有的 `www` 构建产物。

- 首次打开独立预览前先等待路由就绪，避免挂载侧栏造成离线 API 误报。

测试仅验证前端语义、组件编译和界面操作。后端接入后仍须按实施计划完成回环、迁移、原生依赖、串口、真实电表和认证验收；前端 capability 不代替后端权限和参数校验。
