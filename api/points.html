测点操作 API ​

测点数据读写相关的 API 接口文档。

获取测点表格数据 ​

http
GET /api/device/table?channel_id={id}&page={page}&page_size={size}
1

查询参数:

参数类型说明
channel_idint设备通道 ID
pageint页码，从 1 开始
page_sizeint每页数量
frame_typeint测点类型过滤（可选）

响应示例:

json
{
  "code": 200,
  "data": {
    "total": 100,
    "items": [

        "id": 1,
        "name": "A相电压",
        "address": 0,
        "value": 220.5,
        "frame_type": 0,
        "decode": "0x42"
      }
    ]
  }
}
